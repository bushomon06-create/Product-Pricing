# مُثمّن | أداة تتبع تكاليف الإنتاج والتسعير الذكي للأعمال (الإصدار 2.0)

نظام متكامل، خفيف وسريع مصمم خصيصاً لمساعدة الأسر المنتجة، الحرفيين، وأصحاب المشاريع الناشئة والصغيرة على حساب تكاليف الإنتاج بدقة، واقتراح أفضل أسعار بيع لمنتجاتهم تضمن تحقيق هوامش ربح مجزية ومستدامة.

---

```text
└── README.md         # دليل التوثيق والتشغيل
```

## 🌟 أبرز مميزات وتطويرات النظام

1. **حاسبة التكاليف المباشرة والجهد البشري**:
   - حساب تكلفة المواد الخام والتغليف والشحن.
   - تثمين ساعات العمل والجهد المبذول وسعر الساعة العادل لتجنب العمل بخسارة مقنّعة.
   - إمكانية تفصيل مقادير ومكونات المنتج بدقة (Bill of Materials - BOM).
   - إضافة خيارات رسوم بوابات الدفع الإلكتروني (مدى، فيزا، تمارا) وضريبة القيمة المضافة.

2. **اقتراحات التسعير الذكي (Smart Pricing)**:
   - 3 باقات تسعيرية جاهزة:
     - **هامش 20%**: للعروض الترويجية والافتتاح.
     - **هامش 50% (الموصى به)**: المعيار المالي الذهبي للاستدامة والنمو.
     - **هامش 100%**: للمنتجات اليدوية الفاخرة والحصرية.
   - سلايدر حر لتحديد أي نسبة ربح مخصصة.
   - محاكي الخصومات الترويجية مع نظام تحذير لحماية الأرباح من البيع بأقل من التكلفة.

3. **لوحة القيادة والمؤشرات المالية (Dashboard & KPIs)**:
   - مؤشرات أداء رئيسية لحظية (عدد المنتجات، متوسط هامش الربح، المنتج الأعلى ربحاً، إجمالي الأرباح المتوقعة).
   - رسم بياني شريطي لمقارنة التكاليف مقابل الأرباح (Chart.js).
   - رسم بياني دائري (Doughnut Chart) يوضح الهيكل التراكمي للتكاليف وأين تذهب ميزانية الإنتاج.
   - جدول متقدم لفرز والبحث وتصفية المنتجات حسب التصنيف.

4. **حاسبة نقطة التعادل وتغطية المصاريف الثابتة (Break-Even Analysis)**:
   - تحديد عدد القطع المطلوبة شهرياً ويومياً لتغطية الإيجار والكهرباء والاشتراكات والتسويق، والبدء بجني أرباح صافية.

5. **الطباعة والتصدير والنسخ الاحتياطي**:
   - **تصدير إلى Excel (CSV)**: مرمز بـ UTF-8 BOM لضمان ظهور الأحرف العربية بوضوح تام دون أي تشويه.
   - **نسخ احتياطي واستيراد (JSON)**: لنقل البيانات بين الأجهزة أو استعادتها.
   - **بطاقة تسعير رسمية**: نافذة مخصصة لتجهيز بطاقة تسعير وطباعتها أو حفظها كـ PDF مباشرة.

6. **دعم شامل للعملات**:
   - كافة العملات العربية والعالمية (ريال سعودي، ريال يمني، درهم إماراتي، دينار كويتي، جنيه مصري، دولار...).
   - إمكانية تخصيص عملة جديدة وتحديد عدد خاناتها العشرية.
